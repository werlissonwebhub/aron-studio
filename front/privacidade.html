2. Quais dados coletamos

Coletamos apenas os dados necessários para o funcionamento do serviço:

Dados de cadastro e conta: - Nome - Endereço de e-mail - Foto de perfil (quando você faz login com o Google) - Identificador de usuário

Dados técnicos: - Informações de acesso e registros (logs) necessários para segurança e funcionamento.

3. Por que coletamos (finalidades)

Usamos seus dados para: - Criar e gerenciar sua conta; - Permitir que você gere sites e aplicações; - Processar pagamentos e gerenciar créditos; - Enviar notificações relacionadas ao serviço; - Melhorar a plataforma com base em feedback; - Cumprir obrigações legais; - Garantir a segurança e prevenir fraudes.

Cada dado é coletado com uma finalidade específica e não usamos seus dados para outros fins sem informá-lo.

4. Base legal

Tratamos seus dados com base em: - Execução de contrato: para fornecer o serviço que você contratou; - Consentimento: quando você aceita esta Política ao se cadastrar; - Obrigação legal: para cumprir a lei (ex: registros fiscais); - Legítimo interesse: para segurança e melhoria do serviço, sempre respeitando seus direitos.
